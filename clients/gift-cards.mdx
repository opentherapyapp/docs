A gift card is credit with a code attached. Whoever holds the code can put it towards the cost of a session with any therapist on Open Therapy. It doesn't book anything — the recipient chooses their own therapist.

## Buying one

You need an Open Therapy account, because the card is issued against it.

<Steps>
  <Step title="Choose an amount">
    A suggested amount or your own. The minimum is \$50 and the maximum is \$1,000.
  </Step>
  <Step title="Add the recipient">
    Their name and email address, plus an optional message of up to 2,000 characters, sent with your name on it.
  </Step>
  <Step title="Choose when it arrives">
    Send it now, or pick a date to send it on.
  </Step>
  <Step title="Pay">
    By debit or credit card. The purchase is with Open Therapy rather than with a therapist.
  </Step>
</Steps>

The card becomes usable once the payment clears, and you both get a confirmation email. If the payment fails, no code is issued and nothing is sent.

## The code

Codes look like `OT-A7KD-3M9P-QX42`: the prefix `OT-`, then twelve characters in groups of four. The alphabet leaves out `0`, `1`, `I` and `O`. Each code is unique and generated when the card is issued.

Keep the email — the code is the card.

## Using one at booking

Enter the code in **Gift card code (optional)** on the booking page, before you pay.

| | |
|---|---|
| The gift card covers the whole session | Nothing is charged to your payment card, and you're not asked for one |
| It covers part of it | The gift card balance goes first, and only the remainder is charged to your payment card |
| It's worth more than the session | Only what the session costs is taken. The rest stays on the gift card for next time |
| The code is wrong or already spent | You're told before you pay, and the booking waits |

One code per booking. If the balance runs out between the price being quoted and the payment going through, the booking fails rather than going ahead half-paid, and you're told the card has been drained.

## What the receipt says

| | |
|---|---|
| The gift card covered the whole session | **Paid with: Gift card**, for the full session price |
| It covered part of it | The amount charged to your payment card, with that card named |

See [Invoices and receipts](/clients/invoices-and-receipts).

## Expiry

Gift cards don't expire, and there's no fee for leaving a balance sitting there.

## If a session is cancelled

<Info>
  Returning gift card credit after a cancellation isn't automated yet. Write to
  [billing@opentherapy.app](mailto:billing@opentherapy.app) with the code and the session date and
  we'll put it back by hand. Anything charged to your payment card is refunded the usual way — see
  [Cancellations and refunds](/clients/cancellations-and-refunds).
</Info>

## If the recipient never got the email

Check the address you typed, then their spam folder — the email arrives from Open Therapy, not from you. If it's still missing, write to [support@opentherapy.app](mailto:support@opentherapy.app) with the recipient's email address and the date you bought it, and we'll resend it.
